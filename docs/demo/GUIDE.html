Flight Journal / 航迹

This demo uses 20 fictional flights and 2 canceled examples. Explore the map, select a route, search flights and switch between English and Chinese. No workbook, email account or personal travel data is accessed.

演示包含 20 段虚构航班和 2 条取消示例，可探索地图、点击航线、搜索航班并切换中英文。演示不会读取 Excel、邮箱或个人行程。

Your own workbook / 使用自己的 Excel

Download the source, install Python 3.10+, run python -m pip install -r requirements.txt, configure your workbook in outputs/flight-journal/config.json, and run python outputs/flight-journal/app.py. Open http://127.0.0.1:8765. See the README for the workbook format.

下载源码并安装依赖后，配置 Excel 路径即可本机运行，Windows 可双击启动文件。保存 Excel 后约 3 秒自动更新，完整步骤见中文 README。
