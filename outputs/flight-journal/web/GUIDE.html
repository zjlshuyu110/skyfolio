About this demo

The demo contains 20 fictional flights and 2 canceled examples. You can browse the map, select routes and search flights. It does not access your workbook or email.

Use your own workbook

Download the source and install Python 3.10 or later. From the project folder, run:

python -m pip install -r requirements.txt
python outputs/flight-journal/app.py --workbook "/path/to/flights.xlsx"

Open http://127.0.0.1:8765/?lang=en. The app checks for saved workbook changes every 3 seconds.

Use English sheet names such as Flights and columns such as Departure date, Origin and Destination. See the README for the full format.

演示说明

包含 20 段虚构航班和 2 条取消示例，可查看地图、选择航线和搜索航班。演示不会读取你的 Excel 或邮箱。

使用自己的 Excel

下载源码并安装 Python 3.10 或更新版本，在项目目录运行：

python -m pip install -r requirements.txt
python outputs/flight-journal/app.py --workbook "/path/to/flights.xlsx"

打开 http://127.0.0.1:8765/?lang=zh-CN。保存 Excel 后，界面会在约 3 秒内更新。

支持中英文表格，格式见 中文 README。
